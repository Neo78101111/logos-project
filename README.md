**Logos** — это веб-приложение-помощник для практики стоицизма, созданное в рамках изучения Spring Boot.

Идеей проекта было создание стоического планера, в котором пользователь имел бы возможность планировать свою жизнь (ставить долгосрочные цели (в моем проекте - мечты), разбивать их на подцели, подцели на задачи).

## Функциональные возможности

### Пользователи и безопасность
- Регистрация / аутентификация (Spring Security, BCrypt)
- Роли: `USER` и `ADMIN`
- Личный кабинет: смена пароля, обновление профиля (email, даты рождения/смерти)
- Администратор может создавать/редактировать/блокировать пользователей, менять роли

### Календарь
- Сетка месяца с карточками дней
- Для каждого дня можно:
  - Добавлять/редактировать/удалять задачи (с приоритетом HIGH/MEDIUM/LOW)
  - Оценить день по стоическим добродетелям (Мудрость, Мужество, Умеренность, Справедливость) и общей удовлетворённости
  - Просмотреть все задачи и оценку
- Автоматический расчёт статуса дня: PAST / TODAY / FUTURE
- Статистика по месяцу: количество оценённых дней, средняя удовлетворённость, выполненные / общие задачи

### Мечты и цели
- Создание мечт (с фото-ожиданием)
- К каждой мечте можно добавить цели с дедлайнами
- Возможность отметить цель выполненной, редактировать, удалять
- По достижении мечты – загрузить фото-результат и итоговый комментарий
- Автоматический таймер обратного отсчёта до дедлайна цели (красная анимация при ≤3 днях)

### Таймер жизни (Memento Mori)
- На навбаре отображается оставшееся время (годы, месяцы, дни, недели) на основе даты смерти
- Рассчитывается процент прожитой жизни

## 🛠️ Технологии

| Категория            | Технологии |
|----------------------|------------|
| **Backend**          | Java 17, Spring Boot 4.0, Spring Security, Spring Data JPA, Hibernate |
| **База данных**      | PostgreSQL (основная), H2 (тесты) |
| **Миграции**         | `spring.jpa.hibernate.ddl-auto=create-drop` (для разработки) |
| **Фронтенд**         | Thymeleaf, Bootstrap 5, FontAwesome, jQuery, Vanilla JS |
| **Сборка**           | Maven |
| **Контейнеризация**  | Docker, Docker Compose |
| **Логирование**      | SLF4J + Logback |
| **Тестирование**     | JUnit 5, Mockito, Spring Boot Test, MockMvc |
